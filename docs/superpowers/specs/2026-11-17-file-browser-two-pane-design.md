# 资源管理器两段式布局设计

## 目标

将网页右上角文件夹图标打开的资源管理器，从“文件夹树｜文件列表｜预览”三段式改为“文件列表｜预览”两段式，为文件名和内容预览腾出空间。

## 布局与导航

- 移除桌面端左侧文件夹树，不再请求或渲染树节点。
- 保留顶部工具栏的后退、前进、上一级、路径面包屑、刷新和当前文件夹筛选；这些控件继续提供全部目录导航能力。
- 中间文件列表占据预览以外的全部剩余宽度；文件夹项目仍可点击进入。
- 右侧预览保持现有行为：选中文件时预览，未选择时显示空状态。
- 手机端现有列表与全屏预览切换不变。

## 帮助文本

“资源管理器”帮助改为说明两段式的文件列表和预览，并指出通过顶部导航控件进入文件夹。

## 验证

- 更新组件测试，确认桌面端不渲染文件夹树，仍渲染列表、预览和导航控件。
- 运行相关前端测试与类型检查。
