# 工作台空状态

## 目标

用户从任一 AI 工具会话返回首页（工作台）时，如果工作台没有运行中或待查看的会话，显示已有的“今日统计”卡片，而不是说明文字。

## 范围

- 复用现有 `TodayStats` 组件和统计接口，不新增统计数据或卡片。
- 点击首页/工作台时清除当前选中的会话，使桌面端也回到首页内容。
- 工作台为空时展示统计卡片。
- 统计卡片显示时，移除其后的“运行中的任务”说明和手机端“现在没有正在回复的会话”提示。
- 工作台存在运行中或待查看会话时，继续由现有会话列表承担内容展示，不显示新的说明卡片。

## 验收条件

1. 点击首页/工作台后不再保留已打开会话的正文。
2. 空工作台显示今日统计，且统计卡片下没有被移除的说明文字。
3. 工作台有会话时，现有会话列表和打开会话操作保持不变。
4. 桌面端与手机端遵循相同的空工作台规则。
